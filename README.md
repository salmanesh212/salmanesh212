## 🚀 Featured Projects

### [🏭 Industrial Performance Monitoring System](https://github.com/salmanesh212/PredictiveMaintenance--OEEAnalytics)
*Internship Project — ROTOPRINT SAC*

A web-based industrial monitoring application designed to digitalize production performance tracking and introduce predictive maintenance.

- Digitalization of production monitoring and **TRS/OEE** indicators.
- Predictive maintenance using **Random Forest**.
- Model interpretability with **SHAP**.
- Advanced cross-validation and model error analysis.
- Production performance monitoring through a Flask web application.

**Tech Stack:** Python, Flask, Scikit-learn, Random Forest, SHAP, Pandas, NumPy.

### 🤖 AI Helpdesk Chatbot

An intelligent chatbot combining Large Language Models and Retrieval-Augmented Generation to provide contextual answers.

- RAG architecture for knowledge-based question answering.
- React frontend and FastAPI backend.
- PostgreSQL and Redis integration.
- Vector databases: Chroma / Qdrant.
- Multiple LLM providers with automatic fallback.

**Tech Stack:** Python, FastAPI, React, PostgreSQL, Redis, RAG, Chroma, Qdrant, LLMs.

### [📦 StockIMS — Inventory Management System](https://github.com/salmanesh212/stockims)

A web application designed to manage inventory operations and stock movements.

- Inventory entries and exits management.
- Database management using MySQL and JPA.
- Spring Boot backend architecture.
- Thymeleaf-based user interface.

**Tech Stack:** Java 21, Spring Boot, Spring Data JPA, MySQL, Thymeleaf.

### [🎓 StudentManager — Student Management System](https://github.com/salmanesh212/miniprojet-cpp-SABER-SHAME)

A desktop application developed to manage student records using object-oriented programming.

- C++ and Qt6 desktop interface.
- Object-Oriented Programming (OOP).
- STL and exception handling.
- File-based data persistence.
- Collaborative development in a two-person team.

**Tech Stack:** C++, Qt6, STL.

### [🎮 CYBOTICS TAP — Interactive Reaction Game](https://github.com/salmanesh212/Game-Cybotics)
*CYBOTICS ESITH Club Fair*

An interactive mobile reaction game developed for the ESITH Club Fair.

- QR Code integration to let participants join using their smartphones.
- Player registration and difficulty selection.
- Real-time reaction-based gameplay.
- Live leaderboard and Top 10 ranking.
- PC Arena interface for displaying scores.
- Admin dashboard for event management.
- Real-time communication using Socket.IO.

**Tech Stack:** React, Vite, TypeScript, Node.js, Express, Socket.IO, PostgreSQL.

🔗 [Live Demo](https://cybotics-tap.vercel.app)

### [📱 QR Questions — Interactive QR Code Q&A Platform](https://github.com/salmanesh212/QuestionsWithQRcode)

A web application that allows participants to scan a QR Code and interact with live activities, submit questions, and participate in interactive sessions without creating an account.

- QR Code generation in PNG and SVG formats.
- Mobile-friendly participant interface.
- Question submission without mandatory account creation.
- Real-time question management and moderation.
- Multiple activities and event management.
- Live question approval, pinning, and projection.
- CSV export for collected questions.

**Tech Stack:** Next.js, TypeScript, Supabase, PostgreSQL, Vercel.
